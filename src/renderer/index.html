UniChat

Ajouter un service

Supprimer le service retire son entrée du registre et sa vue. La session (connexion) peut être conservée : le service réapparaîtra déjà connecté s'il est réajouté avec la même URL.

Choisir vos services IA

Cliquez sur les services que vous voulez. Un clic les active, un second clic les désactive (session et historique conservés).

Relayer une demande

Saisissez votre prompt ici, pas dans le site. Cliquez sur un service : le prompt est copié dans le presse-papiers et le service s'affiche. Collez-le (Ctrl+V) et envoyez. Le prompt reste mémorisé dans UniChat.
